# Taufiq Syed Portfolio

[taufiqsyed.com](https://taufiqsyed.com)

A tmux-inspired portfolio built with Next.js.

## Run

```sh
pnpm dev
```

## Build

```sh
pnpm lint
pnpm build
```

## Content

Portfolio data lives in `app/portfolio-content.ts`.

To regenerate the ANSI portrait:

```sh
pnpm ascii:profile
```
